# Open Lakehouse Lab

The Open Lakehouse Lab aims to provide an environment where folks can learn about, experiment with, and 
experience the Lakehouse architecture and its associated open-source technologies.

The original motivation for this lab stemmed from the need to have a hands-on platform to
validate implementations and patterns in the delta-rs project and to share these learnings
with the broader community.

The desktop app for local lakehouse environments lives in
[luminescent-lakehouse](https://github.com/open-lakehouse/luminescent-lakehouse)
(`apps/desktop`). It replaced the Tauri app that used to be here.
